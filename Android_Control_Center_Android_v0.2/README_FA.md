# Android Control Center 0.2

نسخه اولیه قابل آزمایش برای ارتباط دو گوشی اندرویدی که برنامه روی هر دو نصب شده باشد.

## قابلیت‌های این نسخه
- سرور و کلاینت Wi-Fi / هات‌اسپات با TCP
- سرور و کلاینت Bluetooth Classic RFCOMM برای دستگاه‌های از قبل Pair شده
- احراز هویت ساده با کد شش‌رقمی که گوشی میزبان تولید می‌کند
- دریافت مدل سازنده، مدل دستگاه و نسخه اندروید گوشی میزبان
- دریافت درصد باتری گوشی میزبان

## محدودیت‌ها
- این نسخه برای آزمایش اولیه ارتباط است؛ انتقال فایل، موقعیت، دوربین، میکروفون و اجرای فرمان‌های مدیریتی در آن پیاده‌سازی نشده‌اند.
- برای Wi-Fi هر دو گوشی باید در یک شبکه باشند. در هات‌اسپات، IP میزبان به تنظیمات گوشی/هات‌اسپات وابسته است.
- برای Bluetooth ابتدا دو گوشی را از تنظیمات اندروید Pair کنید. اتصال RFCOMM فقط در دستگاه‌هایی کار می‌کند که Bluetooth Classic را پشتیبانی کنند.
- کد شش‌رقمی تأیید اتصال است، نه رمزنگاری کامل؛ فقط روی شبکه مطمئن آزمایش شود.
- هر دو گوشی باید برنامه را نصب و میزبان باید خودش سرور را فعال کند.

## ساخت APK
پروژه را در Android Studio باز کنید، منتظر Sync بمانید و از Build > Build APK(s) استفاده کنید.
